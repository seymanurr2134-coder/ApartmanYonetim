C# ve SQL Server ile Geliştirilmiş Apartman Yönetim Sistemi 🏢💻

Bu videoda, bir apartman veya sitenin tüm idari ve finansal süreçlerini dijitalleştiren Apartman Yönetim Sistemi otomasyonumu inceliyoruz.
Öne Çıkan Özellikler:
Gelişmiş Yönetici Paneli: Kullanıcı yetkilendirme, sakin ve daire veri yönetimi.
Finansal Takip: Borçlandırma süreçleri, aidat takibi ve gelir/gider dinamik raporlaması.
Veritabanı Mimarisi: Arka planda veri tutarlılığını ve güvenliğini sağlayan SQL Server ilişkisel veritabanı (Triggers & Procedures).
🛠️ Teknoloji Yığını: C#, .NET, SQL Server
